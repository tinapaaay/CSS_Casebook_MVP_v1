Chapter 09 · CSS Flexbox

Flexbox field guide

Seven compact lessons and a live control room for understanding direction, wrapping and alignment without memorizing isolated property values.

Learning objectives

  • Identify the main and cross axes for every direction.
  • Control direction, wrapping and item distribution.
  • Choose the correct alignment property without guessing.
  • Diagnose and explain a common Flexbox layout failure.

Before you begin

Know basic CSS declarations, class selectors, width and height. Flexbox item sizing is outside this first chapter release.

Estimated chapter time: 30–45 minutes

Lesson 01

Main and cross axes

A flex container has a main axis and a perpendicular cross axis. The main axis follows flex-direction; the cross axis always runs across it.

Common mistake: assuming the main axis is always horizontal. It changes when the direction becomes a column.

Lesson 02

flex-direction

row and row-reverse create a horizontal main axis. column and column-reverse create a vertical one. Reverse values also reverse the visual start and end.

row →row-reverse ←column ↓column-reverse ↑

Lesson 03

flex-wrap

Flex items stay on one line with nowrap, even when space becomes tight. wrap permits new flex lines, while wrap-reverse reverses the cross-axis stacking direction.

12345

Lesson 04

flex-flow

flex-flow combines direction and wrapping in one shorthand. Write the direction first and wrapping behavior second.

.container {
  display: flex;
  flex-flow: row wrap;
}

Lesson 05

justify-content

This distributes items along the main axis. Use start or end alignment, center the group, or distribute remaining space between and around items.

flex-startcenterflex-endspace-betweenspace-aroundspace-evenly

Lesson 06

align-items

This aligns items on the cross axis. stretch is the default when items do not have a fixed cross size; start, center and end position the items as a group.

justify-contentMain axis

Follows the selected direction.

align-itemsCross axis

Works perpendicular to it.

Lesson 07

The centering pattern

.container {
  display: flex;
  justify-content: center; /* main axis */
  align-items: center;     /* cross axis */
}

Both declarations are needed because each property controls only one axis. The container also needs available space for the centering to be visible.
